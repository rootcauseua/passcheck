# passcheck

![version](https://img.shields.io/badge/version-1.0.0-red)
![python](https://img.shields.io/badge/python-3.10%2B-blue)
![license](https://img.shields.io/badge/license-MIT-green)

Офлайн-аналізатор надійності паролів. Перевіряє довжину, різноманітність
символів, наявність у публічних списках витоків та оцінює приблизний час
на brute-force підбір.

**Нічого нікуди не надсилається** — усі перевірки виконуються локально,
мережа не використовується.

## > демо

```
$ python passcheck.py

  Довжина:         6
  Малі літери:     ні
  Великі літери:   ні
  Цифри:           так
  Символи:         ні
  У списку витоків:ТАК — замінити негайно
  Ентропія:        19.9 біт
  Час на злом:     миттєво
  Оцінка:          [░░░░] Дуже слабкий (пароль у відкритих словниках)
```

  Великі літери:   так

## > встановлення

```bash
git clone https://github.com/rootcauseua/passcheck.git
cd passcheck
```

Залежностей немає — потрібен лише Python 3.10+.

## > використання

```bash
# передати пароль аргументом
python passcheck.py "мій_пароль"

# або ввести приховано (нічого не висвітиться на екрані)
python passcheck.py
```

| Прапорець   | Опис                     |

## > як це рахується

- **Ентропія** — `довжина × log2(розмір_алфавіту)`, де алфавіт залежить
  від того, які типи символів використані (малі/великі літери, цифри, спецсимволи).
- **Час на злом** — оцінка на основі умовної швидкості підбору
  10 млрд хешів/сек (орієнтир для швидких, непосолених хешів типу MD5/SHA1;
  для bcrypt/argon2 реальний час буде на порядки більшим).
- **Список витоків** — невеликий приклад найпоширеніших паролів
  (`data/common_passwords.txt`). Для реального використання рекомендується
  підключити повний список на кшталт `rockyou.txt`.
